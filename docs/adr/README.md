# Architecture decision records

ADRs capture decisions that survive Phase 0. Use consecutive names such as
`0001-terminal-graphics-protocol.md`.

Each ADR contains:

1. status and date;
2. context and the question being decided;
3. considered alternatives;
4. measured evidence;
5. decision;
6. consequences and follow-up work.

A spike result is not an ADR. The result records observations; the ADR records the
decision derived from them.
